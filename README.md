Mello – AI-Powered English Speaking Tutor

About the Project :

Mello is an AI-powered, voice-based English learning application designed to help users improve their English-speaking skills and communication confidence through interactive conversations.

 Features :

* Voice-based English conversation practice
* AI-powered interactive learning experience
* Speaking practice and feedback
* User-friendly interface
* Personalized learning experience

Tech Stack :

* React.js
* Next.js
* TypeScript
* Tailwind CSS
* AI and voice interaction APIs

 Getting Started :

Prerequisites :

* Node.js
* npm

Installation

git clone https://github.com/RakshithaMothukuri07/Mello-ai-english-tutor.git
cd Mello-ai-english-tutor
npm install
npm run dev

Open http://localhost:3000 in your browser.
